Избранное — плитки вверху колонки

Чтобы добавить сайт, перетащите вкладку из колонки или ссылку со страницы на плитки.

Закреплённые вкладки и папки никогда не закрываются автоматически.

Фильтры EasyList и uBlock Origin. При первом включении списки загружаются около минуты.

У каждого пространства отдельные входы на сайты, cookie и данные — как профили. Переключение: ⌃1…⌃9.

Устанавливайте расширения из официального магазина: откройте страницу расширения и нажмите «Установить». Иконки появятся справа в панели.

Скилл — готовый запрос к Gemini. Вызывается кнопкой в чате или в командной строке через «/». Текст открытой страницы добавляется автоматически.

Перевод отправляет в Google только текст страницы.

Свой DNS работает по защищённому протоколу DNS-over-HTTPS: укажите адрес вида https://…/dns-query (можно несколько через пробел). Настройка действует на все пространства и окна Luch.

Luch подставляет логины и пароли из приложения «Пароли» (связка ключей iCloud), как Safari: щёлкните по полю входа на сайте и выберите учётную запись. Пароли остаются в macOS — Luch получает пароль только для того сайта, где вы выбрали вход.

Код нужно вводить после каждого перезапуска Luch, так же как в расширении iCloud Passwords для Chrome. Для этого нужна macOS 14 или новее и включённые Пароли iCloud.

Перенесите закладки, историю и входы на сайты из Chrome, Arc, Dia, Edge, Brave, Яндекс Браузера, Opera, Vivaldi или Firefox. Можно выбрать несколько браузеров сразу.
